☁️ Google Sheets 雲端同步

設定後，資料會自動儲存到你的 Google Sheets，換電腦或清瀏覽器都不怕。
尚未設定？請先按下方步驟建立 Apps Script，複製 URL 後貼入下方。

📋 建立 Apps Script 步驟（點我展開）
① 建立 Google Sheets
前往 sheets.google.com，建立新試算表，命名為「飲食控制記錄」（名稱隨意）。

② 開啟 Apps Script 編輯器
在試算表上方選單點「擴充功能」→「Apps Script」。

③ 貼上程式碼並設定金鑰
刪除編輯器裡原本的內容，貼上下載的 diet_sync_script.gs 內容。
找到第一行 const SECRET_TOKEN = 'diet-2024-mj-secret-change-this';，把引號裡的字串改成你自己設定的任意密碼（例如 mj-diet-mypassword123），然後按💾儲存。這個字串就是你的私密金鑰，沒有它就無法讀寫你的資料。

④ 部署為 Web App
右上角點「部署」→「新增部署作業」→ 類型選「網頁應用程式」→ 執行身分選「我」→ 存取權選「任何人」→ 按「部署」。
（第一次會要求授權，按「授予存取權」並用你的 Google 帳號登入允許即可。）

⑤ 複製 URL 並填入網頁
部署完成後複製顯示的網址（格式：https://script.google.com/macros/s/…/exec）。回到飲食記錄網頁，在上方「Apps Script URL」欄位貼入網址，在「私密金鑰」欄位填入你在步驟③設定的金鑰字串，再按「儲存並同步」。

⑥ 完成！
之後每次新增或修改飲食記錄，都會在 1.5 秒後自動同步到 Google Sheets。換電腦時只要開網頁、填入同一個 URL，資料就會自動載入。
